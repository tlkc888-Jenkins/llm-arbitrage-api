ASX Announcements Monitor

Track stock announcements from the Australian Securities Exchange using free hosted tools. No API keys required.

What This Does

This example shows how to build an agent that monitors ASX company announcements — the kind of updates that move stock prices. It uses Autropic's fetch tool to pull data directly from ASX's public pages.

No API keys needed. ASX publishes announcements on public web pages. We just fetch and parse them.

Tools Used

🌐 fetch 🕐 time 🔢 calculator

The Code

Here's a minimal Python example that fetches announcements for a specific ASX ticker:

import requests

def autropic_call(server: str, tool: str, arguments: dict):
    """Call any Autropic hosted tool with one HTTP request."""
    r = requests.post(
        f"https://tryautropic.com/mcp/{server}/tools/call",
        json={"name": tool, "arguments": arguments},
        timeout=30,
    )
    r.raise_for_status()
    return r.json()

# Fetch ASX announcements for CAE (Cannindah Resources)
url = "https://www.asx.com.au/asx/v2/statistics/announcements.do?asxCode=CAE&by=asxCode&period=M6&timeframe=D"

page = autropic_call("fetch", "fetch", {"url": url})
html = page.get("content", "")

print(html[:800])  # Preview the response

Extend It
