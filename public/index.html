How it works

Call our API before each LLM call. We tell you the cheapest model that can handle your task.

# Get cheapest model for simple tasks (no signup required)
curl "https://tryautropic.com/v1/cheapest?tier=simple"

# Response
{
  "tier": "simple",
  "recommendations": [{
    "provider": "GROQ",
    "model": "llama-3.1-8b-instant",
    "inputCostPer1m": 0.05,
    "outputCostPer1m": 0.08
  }]
}

For AI agents (MCP)

Add AutropicAI to Claude Desktop or any MCP-compatible agent:

claude_desktop_config.json

{
  "mcpServers": {
    "autropicai": {
      "command": "npx",
      "args": ["github:tlkc888-Jenkins/autropicai-mcp"]
    }
  }
}

Your agent gets a get_cheapest_model tool — it can find the cheapest model for any task automatically.
