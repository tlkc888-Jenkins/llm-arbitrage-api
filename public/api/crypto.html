Free Cryptocurrency Price API

Real-time crypto prices. No API key needed.

Endpoint: POST https://tryautropic.com/mcp/crypto-prices/tools/call
Authentication: None required

Quick Start

curl -X POST https://tryautropic.com/mcp/crypto-prices/tools/call \
  -H "Content-Type: application/json" \
  -d '{"name":"get_price","arguments":{"symbol":"BTC"}}'

Python Example

import requests

def get_crypto_price(symbol):
    response = requests.post(
        "https://tryautropic.com/mcp/crypto-prices/tools/call",
        json={"name": "get_price", "arguments": {"symbol": symbol}}
    )
    return response.json()["content"]

btc = get_crypto_price("BTC")
eth = get_crypto_price("ETH")
print(f"BTC: ${btc['price_usd']:,.2f}")
print(f"ETH: ${eth['price_usd']:,.2f}")
