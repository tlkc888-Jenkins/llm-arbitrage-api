Free Calculator/Math API

Evaluate any math expression. No API key.

Endpoint: POST https://tryautropic.com/mcp/calculator/tools/call
Authentication: None required
Safety: Sandboxed evaluation, no code execution

Quick Start

curl -X POST https://tryautropic.com/mcp/calculator/tools/call \
  -H "Content-Type: application/json" \
  -d '{"name":"evaluate","arguments":{"expression":"(15 * 3) + sqrt(144)"}}'

Response

{
  "content": {
    "expression": "(15 * 3) + sqrt(144)",
    "result": 57
  }
}

Supported Operations

  • Basic: + - * / %
  • Powers: 2^10 or pow(2, 10)
  • Roots: sqrt(16), cbrt(27)
  • Trig: sin, cos, tan, asin, acos, atan
  • Logarithms: log, log10, log2, ln
  • Constants: pi, e
  • Rounding: round, floor, ceil, abs

Examples

# Compound interest
"(1 + 0.05)^10 * 1000"  → 1628.89

# Circle area
"pi * 5^2"  → 78.54

# Hypotenuse
"sqrt(3^2 + 4^2)"  → 5

# Percentage
"250 * 0.15"  → 37.5

Python Example

import requests

def calculate(expr):
    r = requests.post(
        "https://tryautropic.com/mcp/calculator/tools/call",
        json={"name": "evaluate", "arguments": {"expression": expr}}
    )
    return r.json()["content"]["result"]

print(calculate("2^10"))  # 1024
print(calculate("sin(pi/2)"))  # 1.0
