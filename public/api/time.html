Free Time/Timezone API

Current time anywhere. No API key needed.

Endpoint: POST https://tryautropic.com/mcp/time/tools/call
Authentication: None required

Quick Start

curl -X POST https://tryautropic.com/mcp/time/tools/call \
  -H "Content-Type: application/json" \
  -d '{"name":"get_current_time","arguments":{"timezone":"America/New_York"}}'

Response

{
  "content": {
    "timezone": "America/New_York",
    "datetime": "2026-02-12T04:18:00-05:00",
    "date": "2026-02-12",
    "time": "04:18:00",
    "day": "Thursday",
    "unix": 1739350680
  }
}

Parameters

  • timezone (optional) - IANA timezone (e.g., "Europe/London", "Asia/Tokyo"). Defaults to UTC.

Common Timezones

  • America/New_York - US Eastern
  • America/Los_Angeles - US Pacific
  • Europe/London - UK
  • Europe/Paris - Central Europe
  • Asia/Tokyo - Japan
  • Asia/Shanghai - China
  • Australia/Sydney - Australia Eastern

Python Example

import requests

response = requests.post(
    "https://tryautropic.com/mcp/time/tools/call",
    json={"name": "get_current_time", "arguments": {"timezone": "Asia/Tokyo"}}
)
time_data = response.json()["content"]
print(f"Tokyo time: {time_data['time']}")
