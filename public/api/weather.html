Free Weather API

No API key. No signup. Just HTTP.

Endpoint: POST https://tryautropic.com/mcp/weather/tools/call
Authentication: None required
Rate limit: Generous free tier

Quick Start

curl -X POST https://tryautropic.com/mcp/weather/tools/call \
  -H "Content-Type: application/json" \
  -d '{"name":"get_weather","arguments":{"location":"San Francisco"}}'

Response

{
  "content": {
    "location": "San Francisco, CA",
    "temperature": 15,
    "unit": "celsius",
    "conditions": "Partly Cloudy",
    "humidity": 72,
    "wind": "12 km/h NW"
  }
}

Parameters

  • location (required) - City name, address, or coordinates

Use Cases

  • AI agents needing weather context
  • Chatbots answering weather questions
  • Automation workflows
  • Quick prototypes without API key hassle

Code Examples

Python

import requests

response = requests.post(
    "https://tryautropic.com/mcp/weather/tools/call",
    json={"name": "get_weather", "arguments": {"location": "Tokyo"}}
)
weather = response.json()["content"]
print(f"Temperature: {weather['temperature']}°C")

JavaScript

const response = await fetch("https://tryautropic.com/mcp/weather/tools/call", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    name: "get_weather",
    arguments: { location: "London" }
  })
});
const { content } = await response.json();
console.log(`Weather: ${content.conditions}`);
